# Chips

Pills for picking one option (filters, plans) and small tags that describe an exercise.

- Chip: 36px pill, `surface-2`; selected inverts to `text` on `bg`.
- Tag: 24px, 8px radius; the superset tag takes its colour; "Go heavier" uses `accent`.

Hand-written from `src/styles.css` and the matching component in `src/` (static rendition).
