# Card

The default container: surface fill, a 1px line, 22px radius and 20px padding.

- Padding `pad-card` (20); content inside 12 apart (`gap-in-card`); sibling cards 12 apart (`gap-list`).
- Cards use a line, not a shadow; shadows are only for floating layers.
- Eyebrow first (11px, uppercase, `accent-text`), then the content.

Hand-written from `src/styles.css` and the matching component in `src/` (static rendition).
