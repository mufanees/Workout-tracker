# Button

Pill buttons: one lime primary per screen, secondary for everything else, ink when it sits on lime.

- **Primary** (`accent` on `accent-ink`): the one thing to do now. Start, Finish, Save.
- **Secondary** (`surface-2`): other actions.
- **Ink**: actions placed on a lime card (the plan card).
- Heights: `h-md` 44 default, `h-lg` 54 for the main action, `h-sm` 36 only for chips.
- Press feedback: `scale: 0.96` over 150ms ease-out.

Hand-written from `src/styles.css` and the matching component in `src/` (static rendition).
