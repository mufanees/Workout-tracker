# RoutineCard

A routine you can start: its name over a plain list of exercises, with options and Start on the right.

- Name in `card-title`; exercises in `read-list` (Inter, 15px, up to 3 lines).
- Start is the primary button; the ellipsis opens options.
- Cards stack 12 apart.

Hand-written from `src/styles.css` and the matching component in `src/` (static rendition).
