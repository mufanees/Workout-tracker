# CelebrationHero

The card that opens a finished workout or fast: an ink card with lime stripes, the result in huge numbers and a bar toward the goal.

- Always dark (`ink`), stripes from `accent`, radius `r-2xl`.
- Eyebrow says what happened; the number is the result; the bar shows the goal ("Goal 16h · Reached", or "Day earned" when you showed up but stopped early).
- Arrives once: opacity, 12px rise and 4px blur at 300ms `cubic-bezier(0.2, 0, 0, 1)`.

Hand-written from `src/styles.css` and the matching component in `src/` (static rendition).
