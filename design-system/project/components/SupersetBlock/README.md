# SupersetBlock

Exercises done back to back, grouped in one tinted block with the rest timer once after the round.

- The block takes the superset colour (`--ss`); its cards sit 6 apart inside and blocks sit 16 apart, so the group reads as one.
- Concentric radius: block 28 with 6px padding, cards 22.
- Header: "Superset N" and the order ("1a → 1b, then rest"); footer: the rest for the whole round.

Hand-written from `src/styles.css` and the matching component in `src/` (static rendition).
