# SetRow

One set in the workout table: number, previous (tap to copy), weight, reps and the check.

- Rows are 56px (`set-row`) with 46px cells (`set-input`) and a 50px check: big enough to hit mid-set.
- Grey numbers are suggestions (last time or the plan); typed numbers are full strength.
- A done row tints lime and its check fills with `accent`; the check pops in from scale 0.25 with a 4px blur.
- All numbers use tabular figures.

Hand-written from `src/styles.css` and the matching component in `src/` (static rendition).
